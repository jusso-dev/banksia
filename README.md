# Banksia

Self-hosted backup for Microsoft 365 and Entra ID, with restore back into the tenant and scheduled restore tests.

Banksia stores mailbox, OneDrive and (later) SharePoint, Teams and Entra ID data in storage you own, such as Azure Blob or Cloudflare R2 in Australia. The product is the in-tenant restore and the restore-test evidence, not only a copy of the data.

This repository is new. Design, issues and an MVP plan are being written now.

## Status

Pre-design. Do not use this in production.
